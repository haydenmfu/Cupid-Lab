# Try the tree editor

This is a local prototype for feedback on building compatibility trees. No account or real personal information is needed. Your tree starts blank. Click Add your first node to begin.

## A ten-minute test

1. Add a Yes / no question and give it your own wording. Move its settings window using the Settings header.
2. Drag a node. Scroll to zoom, and drag empty grid space to pan.
3. Add a binary question and connect a branch by dragging an output dot to an input dot.
4. Try a two-of-three block with three binary questions. Set those questions to “Input for a block only” if they should only feed that block.
5. Try a Sum score block with two scalar questions. The sum must be strictly greater than its threshold.
6. Delete a connection by clicking its line. Try Undo, Clean up tree, and Fit.
7. Export the tree. In Advanced editor, import it and apply the JSON to restore it.
8. Use Test this tree to explore the sample pair's result.

## What to report

- What were you trying to express?
- What did you expect, and what happened instead?
- Which interaction or label was confusing?
- Were there rules you couldn't express?
- OS, browser, and steps that reproduce a bug.

Share a screenshot or exported tree only if comfortable sharing its contents. Exports include private rule labels and preferences, but not profile photos or answers. Feedback is not sent automatically; send it to the project owner or use the repository's Issues page once available.
